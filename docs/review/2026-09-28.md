## Suggested changes

1. **`scan.py` — tighten remote-EMEA detection.** Evidence: the Afiniti "Senior Manager
   Customer Success" role scored 7.2 and reached you tagged as IE, but your own note
   says it's remote-anywhere-in-Europe, which `profile.md` already says to reject
   outright. The location screen is filing borderline remote-EU roles under a single
   country market instead of catching them as remote-EMEA. Cost: low, but risks
   misclassifying a genuine hybrid/on-site IE role as remote if the JD is ambiguous —
   worth a spot-check on a few examples before trusting it fully.
2. **`scan.py` — blocklist "RevOps Report" (and similar board-as-employer postings).**
   Evidence: your own note says to ignore it — it isn't a real employer, it's an
   aggregator that redirects back to the original LinkedIn posting. Cost: near zero;
   narrow, name-specific filter.
3. **`scan.py` — cross-source dedupe for near-identical postings.** Evidence: the
   OneTrust "Customer Success Manager – Nordics & Benelux" role was scored separately
   from greenhouse (8.0) and Adzuna (8.4) — almost certainly the same job. Dedupe
   already collapses 100+ duplicates a run, so this is a gap in matching across sources
   rather than a missing feature. Cost: moderate — fuzzy title+company matching across
   sources risks merging genuinely different roles at the same company if done too
   loosely, so it needs a conservative threshold.
